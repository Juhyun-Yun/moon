# 🌙 달 모양 탐험대 앱

한 달 동안 달의 모양 변화를 탐구하고 도전 퀴즈로 학습하는 웹앱입니다.
학생은 이름을 골라 학습하고, 결과(점수·정답률·날짜)는 **구글 스프레드시트**에 자동으로 쌓입니다.

> **구조 한눈에 보기**
> - **앱 화면**(index.html) → GitHub Pages에 **한 번만** 배포 → 모든 선생님이 공유
> - **선생님**은 자기 **스프레드시트 사본**을 만들고, 앱 [⚙️ 설정]에서 **자기 시트를 한 번만 연결**
> - **학생**은 공유받은 앱 주소로 들어와 **이름만 고르면** 끝 (설정·로그인·링크 없음)
> - 데이터는 **선생님 각자 사본**에 따로 저장 (반끼리 안 섞임)
> - `index.html`(앱 본체)은 **GitHub에만**, Apps Script에는 **`Code.gs`만** → 코드 노출 최소화

## 1️⃣ 관리자(개발자) — 앱을 GitHub에 배포 (최초 1회)

1. GitHub 저장소에 **`index.html` + `moon.jpg`** 업로드 → Settings → Pages → Source `main /(root)`
   → 나오는 `https://<아이디>.github.io/<저장소>/` 가 **앱 주소**
2. 마스터 스프레드시트 1개 준비: `sheets.new` → [확장 프로그램] → [Apps Script]
   → `Code.gs` 붙여넣기(저장). **`index.html`은 Apps Script에 넣지 않음**(코드 노출 방지)
   → 시트 새로고침 → [🗂 시트 초기화 / 만들기]로 탭 생성
3. (선택) `Code.gs` 상단 `APP_BASE_URL` 에 앱 주소를 적으면 가이드 탭에 자동 표시
4. **앱 주소 + 마스터 시트(사본용) 링크**를 선생님들에게 공유

---

## 2️⃣ 선생님 — 자기 시트를 연결 (각자, 처음 한 번)

스프레드시트 **「📖 선생님 가이드」 탭**에 색깔 안내가 들어 있습니다. 요약:

1. 마스터 시트에서 **[파일] → [사본 만들기]**
2. **[📊 달 모양 탐험대 대시보드] → [🗂 시트 초기화 / 만들기]** (권한 승인)
3. **「학생명단」 B열**에 학생 이름 입력
4. **[확장 프로그램] → [Apps Script] → [배포] → [새 배포] → 웹 앱**
   (실행: 나 / 액세스: **모든 사용자**) → `.../exec` 복사
5. 공유받은 앱을 열고 **[⚙️ 시트 연결 설정] → 주소 붙여넣기 → 저장**
   → "✓ 준비 완료" 가 뜨면 완료 🎉

> **학생**은 그 다음부터 같은 앱 주소로 들어와 **이름만** 고르면 됩니다(설정 없음).
> 연결은 기기(브라우저)별로 저장되므로, 학생이 각자 다른 기기를 쓰면 그 기기에서도 선생님이 한 번 연결해 주세요.

## 🔧 연결 방식 (기술 메모)

GitHub Pages는 정적 호스팅이라 `google.script.run` 을 쓸 수 없습니다.
대신 앱은 선생님이 [⚙️ 설정]에서 연결한 시트 웹앱과 **JSONP(GET)** 로 통신합니다(주소는 브라우저 localStorage에 저장).

- 명단 불러오기: `?action=getStudents&callback=...`
- 결과 저장: `?action=save&student=...&score=...&total=...&details=...&callback=...`

CORS 제약 없이 동작하며, 앱이 Apps Script 안에서 직접 실행될 때는 기존처럼 `google.script.run` 을 사용합니다(자동 감지).
