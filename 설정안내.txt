[ 한눈에 보는 구조 ]

  ┌──────────────────────────────┐
  │  GitHub 앱 (index.html)       │  ← 관리자가 1번 배포, 모두 공유
  └───────────────┬──────────────┘
                  │ 선생님이 [⚙️ 설정]에서 자기 시트 주소를 1번 연결
       ┌──────────┴───────────┬───────────────┐
       ▼                      ▼               ▼
   김선생 시트 사본       이선생 시트 사본    박선생 …
   (학습기록 따로)        (학습기록 따로)

  ※ 학생은 앱 주소로 들어와 "이름만" 고르면 됨 (설정·로그인·링크 없음).
  ※ 연결은 선생님이 1번만. 학생은 아무것도 입력하지 않음.
  ※ index.html(앱 본체)은 GitHub에만. Apps Script에는 Code.gs만(코드 노출 방지).

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【 A. 관리자(개발자) — 앱을 GitHub에 올리기 (최초 1번) 】

1) GitHub 저장소에 index.html + moon.jpg 업로드
2) Settings → Pages → Source: main /(root) → 저장
3) 나오는 주소 https://<아이디>.github.io/<저장소>/ 가 "앱 주소"
4) 이 앱 주소 + 마스터 스프레드시트(아래 B 1~3) 사본 링크를 선생님들에게 공유
5) (선택) Code.gs 맨 위 APP_BASE_URL 에 3)의 앱 주소를 적으면
   선생님 가이드 탭에 앱 주소가 자동 표시됩니다.

  ※ 마스터 스프레드시트 만들기: sheets.new → [확장 프로그램]→[Apps Script]
    → Code.gs 붙여넣기(저장) → 새로고침 → 메뉴 [🗂 시트 초기화 / 만들기]
    → 「📖 선생님 가이드」 등 생성 → 이 파일을 선생님들이 "사본 만들기" 함.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【 B. 선생님 — 내 시트 연결 (각자, 처음 한 번) 】
  ※ 스프레드시트 「📖 선생님 가이드」 탭에 색깔 안내로도 들어 있습니다.

1단계  내 사본 만들기
   마스터 시트에서 [파일] → [사본 만들기]

2단계  시트 만들기 / 권한 승인
   내 사본 새로고침(F5) → [📊 달의 위상 여행 대시보드] → [🗂 시트 초기화 / 만들기]
   → [권한 검토] → 내 계정 → [고급] → [(안전하지 않음)으로 이동] → [허용]

3단계  학생 이름 입력
   「학생명단」 탭 B열에 학생 이름을 한 줄에 한 명씩

4단계  내 시트를 웹앱으로 배포 (주소 받기)
   [확장 프로그램] → [Apps Script] → [배포] → [새 배포] → ⚙️ → [웹 앱]
   • 실행 계정: 나      • 액세스 권한: 모든 사용자   ← 꼭!
   → [배포] → URL(.../exec) 복사  (= 내 시트 주소)

5단계  앱에 내 시트 연결
   공유받은 앱 주소를 브라우저로 열기
   → 첫 화면 [⚙️ 시트 연결 설정] → 4단계 주소(.../exec) 붙여넣기 → [💾 저장하고 연결]
   → "✓ 준비 완료" + 우리 반 이름이 드롭다운에 나오면 성공!
   ★ 한 번 연결하면 그 기기에 기억됩니다.
     이후 학생은 같은 앱 주소로 들어와 "이름만" 고르면 됩니다.
   ※ 학생이 각자 다른 기기를 쓰면, 그 기기에서도 선생님이 한 번 연결해 주세요.
     (학생은 설정을 만지지 않습니다.)

[ 자주 묻는 질문 ]

Q. 학생이 뭔가 설정해야 하나요?
A. 아니요. 연결은 선생님이 [⚙️ 설정]에서 한 번만. 학생은 이름만 고릅니다.

Q. 학생 결과가 저장이 안 돼요.
A. [배포 → 배포 관리 → 편집 → 새 버전 → 배포] 실행,
   액세스 권한이 "모든 사용자"인지 확인.

Q. 내 데이터가 다른 선생님께 보이나요?
A. 아니요. 결과는 내 사본 시트에만 저장됩니다.

Q. 앱이 "예시 데이터(미연결)"라고 나와요.
A. 선생님이 [⚙️ 시트 연결 설정]에 내 .../exec 주소를 저장했는지 확인하세요.

Q. 코드를 수정한 후 반영하려면?
A. (앱 화면) GitHub에 index.html 다시 업로드.
   (서버) Apps Script [배포 → 배포 관리 → 편집 → 새 버전 → 배포].
   ※ 코드는 자동 동기화되지 않으니 항상 "다시 올리기/붙여넣기" 필요.
