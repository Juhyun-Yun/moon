🌙 달의 위상 여행 — 설정 안내 (단일 백엔드 / 선생님은 사용만)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[ 한눈에 보는 구조 ]

  관리자(개발자)가 최초 1번만 연결해 두면,
  그 다음부터 선생님·학생은 "GitHub 앱 주소" 하나만 쓰면 됩니다.

  ┌──────────────────────────────┐
  │  GitHub 앱 (index.html)       │  ← 관리자가 1번 배포
  │  안에 시트 주소가 박혀 있음     │     (DEFAULT_API_URL)
  └───────────────┬──────────────┘
                  │ 자동 연결 (선생님/학생은 설정 안 함)
                  ▼
        구글 스프레드시트 1개
        (학생명단 / 학습기록 / 선생님 가이드)

  ※ 선생님은 주소 배포·링크 생성을 "하지 않습니다". 그냥 사용만 합니다.
  ※ index.html(앱 본체)은 GitHub에만 둡니다. Apps Script에는 Code.gs만.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【 A. 관리자(개발자) — 최초 1번만 】

1) 구글 시트 만들기:  sheets.new  → 제목 "달의 위상 여행"
2) [확장 프로그램] → [Apps Script]
   → 기본 Code.gs 전체 삭제 → 이 폴더의 Code.gs 붙여넣기 → 저장
   ★ index.html은 Apps Script에 넣지 마세요! (코드 노출 방지)
3) 스프레드시트 새로고침(F5)
   → [📊 달의 위상 여행 대시보드] 메뉴 → [🗂 시트 초기화 / 만들기]
   → 권한 승인 → 「📖 선생님 가이드」「학생명단」「학습기록」 탭 생성
4) Apps Script [배포] → [새 배포] → ⚙️ → [웹 앱]
   • 실행 계정: 나
   • 액세스 권한: 모든 사용자   ← 꼭!
   → [배포] → 나오는 URL(.../exec) 복사
5) 이 폴더 index.html 맨 위 DEFAULT_API_URL 에 그 주소를 붙여넣기
      const DEFAULT_API_URL = 'https://script.google.com/macros/s/XXXX/exec';
6) GitHub 저장소에 index.html + moon.jpg 업로드
   → Settings → Pages → Source: main /(root) → 저장
   → 나오는 주소 https://<아이디>.github.io/<저장소>/ 가 "앱 주소"
7) (선택) Code.gs 맨 위 APP_BASE_URL 에도 6)의 앱 주소를 적어두면,
   선생님 가이드 탭에 학생 접속 주소가 자동 표시됩니다.
8) 6)의 앱 주소를 선생님들에게 공유. 끝!

  ※ 코드를 고치면 Apps Script(또는 GitHub)에 "다시" 올려야 반영됩니다.
    (자동 동기화 안 됨)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【 B. 선생님 — 사용법 (3단계, 배포·링크 없음) 】
  ※ 스프레드시트 「📖 선생님 가이드」 탭에 색깔 안내로도 들어 있습니다.

1단계  학생 이름 입력
   「학생명단」 탭 B열에 학생 이름을 한 줄에 한 명씩
   → 앱의 학생 선택 드롭다운에 자동 표시

2단계  학생에게 "앱 주소" 알려주기
   관리자가 공유한 GitHub 앱 주소를 학생에게 안내
   (학급 게시판/메신저/QR 등)
   ★ 학생은 주소만 누르면 끝 → 이름만 고르고 바로 시작 (초등학생도 쉬움)

3단계  학습 결과 확인
   「학습기록」 탭에 결과가 실시간으로 쌓임
   [📊 달의 위상 여행 대시보드] → [📈 전체 통계 보기]로 그래프·표 확인

[ 선생님용 통계 메뉴 — [📊 달의 위상 여행 대시보드] ]

  📖 선생님 가이드 보기/만들기  — 가이드 탭 생성/새로고침
  🗂 시트 초기화 / 만들기
  🔍 간단 통계 (사이드바)
  📈 전체 통계 보기 (대시보드)
  🔄 학생명단 최신 기록 새로고침
  🔗 학생 접속 링크 보기        — (관리자용) 웹앱 주소 확인

[ 시트 구조 (자동 생성) ]

📖 선생님 가이드  — 색깔 입힌 사용 안내 (맨 앞 탭)

📋 학생명단
   A:번호 B:이름 C:비고 D:최근 학습일 E:최근 점수 F:정답률(%)
   → B열에 이름 추가 시 앱 드롭다운에 자동 표시

📋 학습기록  (누적 — 모든 도전 결과가 한 줄씩)
   A:일시 B:학생이름 C:점수 D:총문제 E:정답률(%) F:세부내용

[ 자주 묻는 질문 ]

Q. 선생님도 주소를 배포하거나 링크를 만들어야 하나요?
A. 아니요. 선생님은 학생 이름 넣고, 앱 주소 알려주고, 결과만 봅니다.

Q. 학생이 뭔가 설정해야 하나요?
A. 아니요. 앱 주소만 누르고 이름만 고르면 됩니다.

Q. 앱이 "예시 데이터"라고 나와요.
A. 관리자가 index.html의 DEFAULT_API_URL을 채워 배포했는지 확인하세요(A-5,6).

Q. 여러 반(선생님)이 데이터를 따로 보고 싶어요.
A. 지금은 한 스프레드시트를 함께 씁니다(학생명단/학습기록 1벌).
   반별 분리가 꼭 필요하면 "반 선택" 기능 추가가 필요합니다(요청 시 작업).
